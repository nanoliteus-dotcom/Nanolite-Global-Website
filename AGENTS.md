# Website requirements

- Preserve the user's supplied branding and existing application deployments.
- All website changes must work on mobile as well as desktop. Check narrow phones (320px), common phones (390px and 430px), and tablets (768px).
- Keep headers, text, images, controls and animation focal points within the visible viewport. Horizontal carousels must scroll inside their own container without making the entire page scroll sideways.
- On Atlas mobile, homepage and Pricing plans stay in a single swipeable row.
- Check the affected mobile menus and the published website after deploying. Report actual verification rather than treating a source push as publication.
